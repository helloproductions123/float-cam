#Cam Float Extension
A cool extension showing your camera in a small floating window. (NOTE: Doesn't work on new tab, must run the extension on another non-CSP tab like wikipedia.com, canva.com, etc.)
To run, go to chrome://extensions (or browser-name://extensions)>Developer Mode and turn it on.
Then, click on "Load Unpacked" and click on the folder (Make sure to unzip the file to make the folder).

Thank you for downloading!
